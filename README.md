Student: Farkhod Sapayev

Course: WEB Technologies 1 (Front End)

## Description

This project demonstrates Flexbox and CSS Grid.
It includes five separate pages connected by a navigation bar.

## Pages

- index.html — Flexbox navigation bar.
- cards.html — Three equal-height cards with hover effects.
- layout.html — Page layout using named CSS Grid areas.
- gallery.html — Nine images with hover captions.
- portfolio.html — Portfolio combining Flexbox and Grid.

## Technologies

- HTML
- CSS
- Flexbox
- CSS Grid

## How to run

1. Download the repository and extract the files.
2. Open index.html in a web browser.
3. Use the navigation bar to open the other pages.
